# Mirage — telegram-бот генерации картинок и видео за Stars (Mage + Vilva)

название задаётся в `.env` (`BOT_BRAND`). на баннере зашиты «3 кредита в подарок» и «за 1 кредит» — при смене `FREE_CREDITS` или цен баннер надо перегенерировать

## что умеет
- **меню:** 🖼 Картинка / 🎬 Видео / 🤖 Агент / ⚙️ Настройки / 💰 Баланс
- **генерация:** нажимаешь 🖼 / 🎬 — появляется панель с выбором модели (все модели mage и vilva), формата, разрешения (для видео — длительности), пишешь текст и получаешь результат. фото с подписью в режиме картинок даёт правку, в режиме видео оживляет фото
- **выбор модели**: семейство (nano banana, seedance, gpt image, mango, kling…) → модель с номером и диапазоном цены; провайдеры пользователю не видны, одинаковые модели показываются по самой выгодной цене; после выбора — обратно на панель генерации
  - mage: все 49 моделей сайта (27 картинок, 22 видео) с ценами, снятыми через их `estimate_cost`
  - vilva: модели подтягиваются при старте из `list_models`, цены — из `list_models` и `bot/vilva_prices.py`
- **оформление**: приветствие с картинкой (`bot/assets/welcome.jpg`, сгенерирована gpt image 2.5 flare), панель генерации с примером промпта и ценой, результат с подписью и кнопками «🔁 ещё вариант» / «🎛 параметры»
- **продвинутый режим:** всё остальное из схем моделей — качество, звук, seed, негативный промпт, шаги и guidance у открытых моделей, улучшение промпта, поиск в интернете у nano banana, доработка лиц и рук у sdxl plus. у vilva подхватываются все enum и флаги из схем generate_*. цена пересчитывается на каждой кнопке, параметры, влияющие на цену (шаги, звук melon, поиск nano banana), учтены по замерам
- **агент vilva:** задача, потом режим (📋 сначала план и смета с кнопками одобрить/отклонить или 🚀 автопилот), потом бюджет. агент может задать вопрос, ответ уходит ему. пока агент работает, внизу висит большая кнопка «⛔ остановить агента». списывается фактический расход, остаток бюджета возвращается
- **оплата:** пакеты кредитов в stars (XTR). цена резервируется заранее и пересчитывается по фактическому списанию у провайдера (mage: `billing.gems_charged`). при ошибке кредиты возвращаются
- **безопасность:** фильтр 18+ и несовершеннолетних, плюс модерация mage. админам приходит уведомление, если у провайдера кончился баланс
- **для админа:** `/stats`, `/refund <charge_id>`, `/give <кр> [user_id]` (выдать кредиты, минус — списать). есть `/terms` и `/paysupport`
- незавершённые запуски агента доотслеживаются после перезапуска бота

## запуск (windows)
```powershell
cd genbot
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env   # вписать BOT_TOKEN, ADMIN_IDS и ключи
py -m bot.check          # проверка ключей mage и vilva, ничего не тратит
py -m bot.main
```

## запуск на vps (ubuntu)
```bash
sudo mkdir -p /opt/genbot && sudo cp -r . /opt/genbot && cd /opt/genbot
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env && nano .env
.venv/bin/python -m bot.check
sudo cp deploy/genbot.service /etc/systemd/system/ && sudo systemctl enable --now genbot
journalctl -u genbot -f
```

## экономика
- цена в кредитах = себестоимость в $ × `MARKUP` / `CREDIT_USD`
- себестоимость: mage — 10 000 gems = $10 (`MAGE_USD_PER_GEM`), vilva — 4 000 кредитов = $21 (`VILVA_USD_PER_CREDIT`)
- 1 кредит бота ≈ $0.033 (`CREDIT_USD`): пакет 100 ⭐ = 40 кр, наценка ×1.6 (`MARKUP`) — маржа ~40% на большинстве моделей, на самых дешёвых выше из-за минимума в 1 кр
- пример: gpt image 2.5 — в mage 9 gems ($0.009) → 1 кр, в vilva 9 кредитов ($0.047) → 3 кр
- цены mage — точная сетка, снятая через их `estimate_cost` (картинки по разрешению и quality, видео — gems в секунду по разрешению); фактическое списание всё равно сверяется по ответу
- фото-референс в mage стоит дороже: gpt image +15 gems, guava 2 / 2 pro +5, grok imagine +3 (quality и 2.0 +15), flux 2 и sd 3.5 +5, grok video +3, wan и ltx ≈ +21%. на панели генерации видна цена «с фото»
- `/prices` (админ) — аудит: себестоимость и цена в кредитах по каждой модели на базовых и максимальных параметрах
- `py -m bot.check` сохраняет полный `list_models` vilva в `vilva_models.json`
- агент: бюджет в кредитах бота переводится в лимит vilva. если агент упирается в лимит, бот останавливает его и не поднимает потолок. если расход по какой-то причине вышел за лимит, запуск отменяется и админу приходит уведомление
